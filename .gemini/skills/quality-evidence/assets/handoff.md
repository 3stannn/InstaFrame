# Delivery handoff

## Outcome
Requested scope, delivered behavior, and explicit non-goals.

## Artifacts
Changed files, migration files, matching contracts, and setup instructions.

## Evidence
| Check | Exact command or procedure | Environment | Result | Limitation |
| --- | --- | --- | --- | --- |
| Populate from actual execution | Do not invent commands/results | Local/test/preview | Pass/fail/skipped | State unverified scope |

## Security boundaries
Identity authority, database role, RLS propagation, tenant membership source, cache isolation, and any privileged exceptions.

## Setup and operation
Required environment variable names (not values), migration order, local start commands, and deployment steps requiring approval.

## Remaining risks
Unresolved issues, unexecuted tests, unavailable services, and concrete next steps.
